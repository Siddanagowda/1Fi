# 1Fi Marketplace

Standalone React/Vite implementation of the 1Fi Shop + Marketplace flow. The original 1Fi source code was not provided, so the existing app screenshots supplied with the assignment were used as the UI reference. Product/EMI data is separated into a mock API layer.

## Run

Requirements: Node.js 18+.

```bash
npm install
npm run dev
```

Open the Vite URL, normally http://localhost:5173.

Production build:

```bash
npm run build
npm run preview
```

## Included

- Shop with Top Brands, Nearby Stores and 1Fi Marketplace tabs
- Product search/category filtering
- Product details and gallery
- Variant and colour selection
- Dynamic no-cost EMI plans
- Mock API with loading/error handling
- Confirmation flow
- Responsive mobile/desktop UI
- Reusable components and Context state
- localStorage persistence

## Scope

Real KYC, mutual-fund pledge, loan underwriting, inventory and payment processing are outside the assignment scope. The final CTA demonstrates the complete frontend flow.
